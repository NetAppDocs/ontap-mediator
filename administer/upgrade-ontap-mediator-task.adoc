= Upgrade ONTAP Mediator
:icons: font
:imagesdir: ../media/

[.lead]
To upgrade ONTAP Mediator to a newer version without upgrading the host OS, download the installation package for the new version and run the installer on the host where ONTAP Mediator is already installed.

NOTE: If you need to upgrade the host OS to a new release and reinstall or upgrade ONTAP Mediator as part of that process, see link:upgrade-host-os-mediator-task.html[Upgrade the host OS and ONTAP Mediator] instead.

.Before you begin

* Verify that your host meets the prerequisites described in link:../install/prepare-install.html[Prepare to install ONTAP Mediator], including the host, firewall, and OS requirements.
* Download the installation package for the new version. See link:../install/download-install-pkg-task.html[Download the ONTAP Mediator installation package].
* NetApp recommends verifying the code signature of the new installation package. See link:../install/verify-code-signature-task.html[Verify the code signature of the ONTAP Mediator installation package].

.About this task

Review the following information before upgrading ONTAP Mediator.

* You should upgrade ONTAP Mediator to the latest version. Older versions still work with all ONTAP releases, but newer versions include security patches for third-party components.

* When you upgrade to a new ONTAP Mediator version that includes the SCST package, the installer automatically upgrades to the recommended SCST version unless a higher version is available. For instructions on manually installing a higher SCST version, see link:host-maintenance-task.html[Maintain the host OS for ONTAP Mediator]. For supported versions, see the link:../release-notes/support-matrix.html#scst-support-matrix[SCST support matrix].

[NOTE]
====
* If the upgrade fails, you might need to try a newer version of ONTAP Mediator.
* From June 15, 2025, you can't install or upgrade ONTAP Mediator 1.9 and 1.8 because their code signing certificates have expired. If the upgrade fails, use the ONTAP Mediator 1.9.1 patch version instead.
====

include::../_include/https-only-mediator.adoc[]

* When you run the installer against an existing ONTAP Mediator installation, it detects the current version and prompts you to confirm the upgrade:
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`
+
`Do you wish to continue? Y(es)/n(o):`

* As part of the upgrade, the installer captures a support bundle of your pre-upgrade configuration and migrates the database before upgrading the ONTAP Mediator software.

* For automation use cases, you can use the `./ontap-mediator-1.13.0/ontap-mediator-1.13.0 -y` command to skip the installer prompts.

.Steps

. Run the installer for the new version and respond to the prompts as required:
+
[source,cli]
----
./ontap-mediator-1.13.0/ontap-mediator-1.13.0
----
+
[NOTE]
====
To skip the signature check during the upgrade, use the
`./ontap-mediator-1.13.0/ontap-mediator-1.13.0 --skip-code-signature-check` command
====
+
The installer detects the existing installation and prompts you to upgrade, then installs the required packages and migrates your configuration.
+
